# Scholarly research foundation

`EXISTING_REFERENCES.md` records the bounded upstream audit and ownership boundaries. `graph.json` contains twelve real work/manifestation/revision nodes and eight source-backed identity edges. It asserts no author identity, institutional affiliation, scientific support, reproduction or citation relationship that was not examined.

Graph predicates have distinct semantics. `cites` never implies `supports`; all edges require source references and a locator. Reviewer-dependent predicates and claims require actual linked review evidence. Planned taxonomy and coverage are maintained separately from this small metadata pilot.

# Research record templates

These templates guide original research notes and review packets. They are not complete catalog records, evidence receipts, consent, or permission grants. Replace instructions with actual observations; retain unknowns explicitly. Never fabricate a required value to finish a template.

| Template | Use |
| --- | --- |
| [research-note.md](research-note.md) | Candidate discovery, comparisons and incomplete findings. |
| [identity-resolution.md](identity-resolution.md) | Work/revision/manifestation or author/organization matching decisions. |
| [claim.md](claim.md) | A bounded author-reported assertion or externally supported claim. |
| [source-rights.md](source-rights.md) | Exact source/material/use assessment with actual terms evidence. |
| [reproducibility-assessment.md](reproducibility-assessment.md) | Planned or actual reproducibility assessment with explicit execution state. |
| [correction-event.md](correction-event.md) | A sourced correction, withdrawal, retraction, identity or rights event. |
| [handoff.md](handoff.md) | Exact producer/consumer artifact and receiving decision. |
| [review-checklist.md](review-checklist.md) | Review scope and real observations, separate from GitHub approval. |

Checklist entries are unchecked until actually performed. Do not use a template to attribute review to an absent person, authorize source use, declare a successful experiment or complete a parent issue.

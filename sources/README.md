# Sources and source-use decisions

`register.json` records four actually inspected primary landing pages. It stores links, dates and limits, not raw pages or paper text. [RIGHTS_NOTES.md](RIGHTS_NOTES.md) records the observed arXiv descriptive metadata CC0 basis for public seed inclusion. `rights.json` records pending internal production-catalog field/operation decisions; the unknown review state does not mean the observed metadata license is unknown. Required uses are declared by each proposal. Mixed-source fields require a decision for every contributing source.

A source check is evidence of what was read, not independent scientific verification. Repository licenses do not relicense upstream materials.

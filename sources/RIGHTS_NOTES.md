# Observed metadata basis and pending catalog review

Observed 2026-10-22. The four seed proposals contain arXiv bibliographic metadata and brief original editorial summaries. The arXiv [license information, Metadata license section](https://info.arxiv.org/help/license/index.html#metadata-license) states that its metadata is covered by the Creative Commons CC0 1.0 public domain dedication. This is an observed source policy, not a claim of independent legal review. The [arXiv API terms](https://info.arxiv.org/help/api/tou.html) separately allow descriptive metadata reuse and distinguish manuscript redistribution, which depends on the applicable copyright holder or article license. API access conditions remain separate from metadata licensing.

This descriptive metadata basis supports including the small bibliographic proposals in a public Git repository. A public repository is itself a distribution channel. `publication_status: withheld` therefore means withheld from the proposed production catalog, website projection and release export; it does not mean the repository files are private or undistributed. Repository setup has not created those services or exports.

The `unknown` values in `rights.json` and proposal `rights_status` represent pending internal decisions for each declared production field and operation. They do not deny or relabel the observed arXiv metadata CC0 basis. The field/use matrix also includes original summaries and local classifications, so the metadata policy is not treated as blanket evidence for every part of a future mixed-source projection. Independent rights-review records remain empty. No actual candidate is currently eligible for release.

The repository contains no copied abstract, manuscript, paywalled article text, figure or dataset. No article license or article redistribution permission was assessed or inferred from the metadata policy. The repository's own software/documentation license does not replace third-party terms. Review the source terms and precise projection again when adding a source, expanding retained fields, exporting records or publishing a production catalog; preserve the source and dated decision rather than inferring permission from a public URL.
